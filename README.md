# Bangalore Weekend Events Map

Interactive web app that aggregates and displays Bangalore weekend events on a map.

## Stack

- **Astro** — static site framework
- **Leaflet** — interactive maps
- **Cloudflare Pages** — hosting & edge functions
- **Cloudflare KV** — event data caching

## Development

```bash
npm install
npm run dev
```

## Deployment

Deployed automatically via Cloudflare Pages on push to `main`.
